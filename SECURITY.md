# Security Policy

## Supported versions

Security fixes target the latest 1.x release. Upgrade to the latest patch release when a fix is published.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/fmalekpour/FTPClientSwift/security/advisories/new). If private reporting is unavailable, open an issue requesting a private contact method without disclosing vulnerability details.

Include the affected version, platform and toolchain, a minimal reproduction, and the potential impact. Do not include production credentials, private keys, tokens, or customer data. Do not disclose an unpatched vulnerability in a public issue.
